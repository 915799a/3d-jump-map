# 🎮 3D 점프맵

Three.js로 만든 3D 웹 점프맵 게임입니다. 하늘 위에 떠 있는 발판을 건너건너 18개 스테이지를 통과해 결승 깃발까지 도달하면 클리어입니다.
빌드 과정 없이 `index.html` 파일 하나로 동작하며, PC와 모바일 브라우저에서 모두 플레이할 수 있습니다.

## 바로 플레이

▶ **https://915799a.github.io/3d-jump-map/**

- **로컬 실행**: 내려받은 폴더에서 `index.html`을 브라우저로 열면 됩니다. (인터넷 연결 필요 — Three.js와 웹폰트를 CDN에서 불러옵니다.)
- GitHub Pages(main 브랜치 /(root))에 배포되어 있어, `main`에 푸시하면 자동으로 반영됩니다.

## 캐릭터

시작 화면에서 4종 중 하나를 고를 수 있습니다. 겉모습만 다르고 능력치는 같으며, 고른 캐릭터는 브라우저에 기억됩니다.

| 캐릭터 | 설명 |
| --- | --- |
| 🐰 토끼 | 분홍 몸에 크림색 배·수염·볼터치, 노란 목도리와 방울, 등 뒤 주머니 |
| 🧑‍🚀 우주인 | 흰 우주복에 점멸하는 가슴 LED와 이름표, 광택 나는 바이저, 등 뒤 산소통과 안테나 |
| 🐧 펭귄 | 남색 몸에 흰 배, 주황 부리와 발, 빨간 털모자와 방울, 빨간 목도리 |
| 🤖 로봇 | 강철 몸체에 청록 LED 눈·입, 가슴 신호등, 머리 옆 주황 귀 장치, 등에서 도는 톱니바퀴 |

### 외형과 애니메이션 디테일

- **공통**: 관절(어깨·다리·목) 구조로 팔과 다리가 자연스럽게 스윙합니다. 달리면 몸이 앞으로 기울고 위아래로 통통 튀며, 점프하면 만세 자세를 취합니다. 가만히 있으면 숨쉬기·두리번거리기·고개 갸웃·눈 깜빡임이 번갈아 나옵니다.
- **🐰 토끼**: 수염과 후드 끈, 주머니가 달렸고 귀 끝이 따로 휘날리며 가끔 한쪽 귀를 씰룩거립니다. 목도리 끝 방울이 흔들립니다.
- **🧑‍🚀 우주인**: 바이저 안에 눈이 보이고 안테나와 가슴 LED가 점멸합니다. 공중에서는 등 노즐에서 불꽃이 나옵니다.
- **🐧 펭귄**: 털모자 방울이 흔들리고 몸통이 좌우로 뒤뚱거리며, 달리면 날개를 파닥거리고 점프하면 날개를 활짝 폅니다.
- **🤖 로봇**: 등 톱니바퀴가 달릴수록 빨리 돌고, 가슴 LED 세 개가 순서대로 깜빡입니다. 공중에서는 입이 “오” 모양으로 바뀌고 발에서 제트 불꽃이 나옵니다.

## 조작법

### PC
- **이동**: `W` `A` `S` `D` 또는 방향키
- **점프**: `Space`
- **시점 회전**: 마우스 드래그
- **일시정지**: `P` 또는 `Esc`
- **시작 / 다시 하기**: `Enter` 또는 화면의 버튼

### 모바일 (터치)
- **이동**: 화면 왼쪽을 드래그하면 나타나는 조이스틱
- **점프**: 오른쪽 아래 **점프** 버튼
- **시점 회전**: 화면 드래그

점프에는 약간의 코요테 타임(발판에서 떨어진 직후에도 한 번 점프 가능)이 있어 발판 끝에서 조금 관대합니다.

## 기믹 상세

- **빙판 (얼음)**: 투명한 하늘색 발판. 마찰이 거의 없어 방향 전환이 늦습니다.
- **컨베이어**: 노란 화살표가 흐르는 발판. 흐르는 방향으로 몸이 밀립니다.
- **깜빡이 발판**: 일정 주기로 사라졌다 나타납니다. 사라진 발판은 밟을 수 없습니다.
- **유리 발판**: 밟으면 금이 가고 곧 부서집니다. 오래 머물지 말고 바로 이동하세요.
- **움직이는 발판**: 좌우/앞뒤로 왕복합니다. 발판 위에 서 있으면 함께 이동합니다.
- **트램펄린**: 닿는 순간 위로 강하게 튕겨 올라갑니다.
- **압착 문**: 벽이 좌우에서 오므라들며 길을 막습니다. 열린 순간을 노려 통과하세요.
- **회전 막대**: 제자리에서 빙글빙글 도는 막대. 닿으면 추락과 같은 판정으로 체크포인트에서 다시 시작합니다.
- **볼링공**: 긴 다리 위를 굴러다니는 구슬. 닿으면 체크포인트로 돌아갑니다.
- **돌풍**: 구간에 들어서면 좌우로 바람이 붑니다. HUD 아래 표시로 방향을 확인하세요.
- **저중력**: 달처럼 중력이 약해져 점프가 길게 떠 있습니다.

## 게임 진행과 편의 기능

- **체크포인트**: 각 스테이지 끝의 깃발에 닿으면 저장됩니다. 떨어지거나 장애물에 닿으면 마지막 체크포인트에서 다시 시작합니다.
- **자동 이어하기**: 체크포인트에 도달할 때마다 진행 상황(스테이지·시간·추락 횟수)이 브라우저에 저장되어, 창을 닫았다 열어도 **이어하기** 버튼으로 이어서 플레이할 수 있습니다.
- **HUD**: 현재 스테이지, 추락 횟수, 플레이 시간, 전체 진행 바를 화면 위에 표시합니다.
- **기록**: 클리어하면 총 시간과 추락 횟수를 보여주고, 최고 기록을 저장합니다. 최고 기록을 갱신하면 “신기록!” 표시가 나옵니다.
- **일시정지 / 처음부터 / 체크포인트로**: `P`·`Esc` 또는 일시정지 버튼으로 멈추고, 일시정지 화면에서 **계속하기**, **체크포인트로**, 또는 **처음부터**(실수 방지를 위해 3초 내 2회 클릭 시 스테이지 1 리셋)를 선택할 수 있습니다.
- **사운드**: 효과음(점프·착지·체크포인트·클리어)과 배경 음악을 켜고 끌 수 있습니다. 모두 Web Audio로 실시간 합성합니다.
- **반응형**: 휴대폰 세로/가로 화면과 데스크톱 창 크기에 맞춰 자동으로 조정되며, 터치 기기에서는 조이스틱과 점프 버튼이 나타납니다.

## 배경음악 (3장르 · 직접 선택)

음원 파일 없이 Web Audio로 그 자리에서 합성하는 3가지 장르 중 원하는 것을 골라 들을 수 있습니다.

| 장르 | 분위기 |
| --- | --- |
| 🎮 아케이드 8비트 | 사각파 멜로디에 통통 튀는 베이스, 킥·스네어·하이햇 |
| 🌌 앰비언트 신스 | 느린 패드 코드에 에코 걸린 종소리, 잔잔한 분위기 |
| ⚡ 일렉트로 펑키 | 4비트 킥에 펑키 베이스라인, 클랩과 오프비트 스탭 |

- **고르는 곳**: 우측 상단 `♪` 버튼을 누르면 장르 목록이 열리고, 일시정지 화면에서도 장르를 변경할 수 있습니다. (시작 화면에서는 음악 선택 칩이 생략되어 깔끔하게 캐릭터 선택과 출발에 집중합니다.)
- **끄기**: 목록의 **음악 끄기**(`🔇`)를 고르면 게임은 효과음만 납니다.
- **저장**: 고른 장르는 브라우저에 저장되어 다음에 켜도 유지됩니다.

## 기술 스택

- **Three.js r128** — 3D 렌더링 (CDN: cdnjs)
- **순수 HTML / CSS / JavaScript** — 프레임워크·빌드 도구 없음, 파일 하나
- **Web Audio API** — 배경 음악과 효과음 합성
- **localStorage** — 캐릭터 선택, 체크포인트 진행 상황, 최고 기록, 배경음악 장르 저장
